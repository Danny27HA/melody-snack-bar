# Melody Snack Bar — Tarjeta digital

Proyecto Angular standalone, responsive y pensado principalmente para abrirse desde un código QR.

## Incluye

- Hero con logo de Melody Snack Bar
- Botones de WhatsApp, Facebook y Google Maps
- Servicios
- Galería con las fotografías proporcionadas
- CTA de cotización
- Dirección y mapa
- Barra fija de acciones en móvil
- Aviso de venta de alcohol solo para mayores de edad

## Ejecutar

```bash
npm install
npm start
```

Luego abre `http://localhost:4200`.

## Compilar

```bash
npm run build
```

El resultado quedará en `dist/melody-snack-bar/browser/`.
